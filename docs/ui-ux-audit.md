# UI/UX 审计

## P1 · 辅导与面试当前轮次（已完成）

- 辅导桌面采用内容主栏与固定信息侧栏；右侧只显示本轮目标、当前卡点、下一步和讲解/微测/复练三阶段，不恢复设备说明墙。
- 辅导移动端把本轮信息收进底部抽屉，抽屉支持 Escape、焦点锁定与恢复、页面滚动锁定；输入器和主操作适配安全区，触控目标不小于 44px。
- 面试桌面左侧聚焦题目、真实转写和作答，右侧展示评分关注点、真实评价或“复盘后生成”以及下一步；不显示伪实时分数。
- 面试移动端保留可见的“结束并复盘”操作，完成后不丢失文字稿；题组和评分标准降为题库内的次级说明。
- 四张确认稿位于 `docs/design/p1-tutoring-interview/`，验收基准为 1536×1024 与 390×844 的浅色/深色、键盘路径、控制台、减少动态效果和横向溢出。

## P0 补充 · 工作台无缝交接（已完成）

- 顶栏与侧栏弥散在接缝处先回到同一实色；工作区由 `<main>` 独占顶部、左侧 1px 共边，只保留 18px 左上圆角，不再使用任何内外阴影、高光或边缘渐隐。
- 主工作区隐藏原生滚动条但保留全部滚动方式，避免右侧滚动轨破坏通用外层边界。
- 弥散色场由带 18px 左上圆角的工作区 frame 单层承载；圆角外侧保持统一实色，`<main>` 不再重复绘制渐变，避免左上角出现彩色三角。
- 桌面所有 `WorkspaceShell` 宿主统一生效；移动抽屉保留必要的浮层边界，折叠侧栏和移动工作区继续自然铺满。

## P0 补充 · 主题字体与壳层连续性（已完成）

- 代码预览、颜色值、Cron、诊断信息、扩展摘要和导入凭据统一消费 `--app-code-font`，内置主题不再切换不同等宽字体。
- 顶栏弥散采用低于工作区的透明度，既延续主题色场又保持应用标题清晰；弥散关闭时不残留背景图层。
- 工作区边界不再绘制顶部或左侧阴影，避免圆角旁出现雾影、楔形或深色残块。

## P0 · 工作台与公考首页（已完成）

本阶段只调整核心工作台、新对话和公考首页的展示与导航，不修改业务数据、IndexedDB v16、AI 协议或服务端 API。

### 首屏保留

- 新对话：标题、“从一个问题开始”和底部输入区。
- 公考首页：日期与同步状态、配置健康摘要、唯一推荐动作、七阶段学习链路和三项今日统计。
- 七阶段固定为导入资料、错题复盘、知识沉淀、知识训练、对话辅导、已安排复盘、Obsidian 输出。

### 移入按需展开

- 配置健康的完整问题、恢复入口和手动录入入口移入默认折叠详情。
- 板块统计、薄弱分布和今日错题队列移入“六大板块”。
- 知识分类、训练队列和模板草稿移入“知识中枢”。
- 面试训练和对话辅导入口移入“面试与辅导”。

### 已解决问题

- 删除空白对话重复说明，保持首次发送后才持久化。
- 所有 `WorkspaceShell` 内容视图统一使用零留白贴合的工作区边界和 18px 左上圆角；顶栏和桌面侧栏不再增加重复直线，工作区不使用阴影，对话内容继承壳层高度并服从圆角裁切，折叠侧栏后自然铺满。
- 移动侧栏改为默认关闭的焦点抽屉，具备遮罩、Escape、焦点恢复和滚动锁定。
- 公考首页从多主操作和说明卡片收敛为一个推荐动作与短状态路径。
- 移动端使用纵向 S 路径自然滚动，关闭抽屉后不会残留视觉覆盖或拦截点击。
- 桌面七阶段路径拆为顶部、转弯、返程和绿色尾钩，线条经过编号圆环中心且不再穿过状态文字。
