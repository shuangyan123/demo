# 全应用操作图标审计

## 规则

- 纯图标仅用于关闭、返回上层、更多、复制、紧凑编辑和刷新，并通过共享 `IconButton` 强制提供可访问名称与 Tooltip。
- 新增、导入、上传、保存、同步、测试、重试、撤销、删除、确认和外部打开使用“Lucide 图标 + 文字”。
- 页签、筛选、状态、领域动作、危险确认和可能产生歧义的操作保留文字。
- 品牌继续使用 `ProviderIcon`，业务图标只从 `AppIcon` 注册表读取，不使用 Emoji、原始 `×` 或 Unicode 功能箭头。

## 本轮结果

| 类别 | 处理 | 代表入口 |
| --- | --- | --- |
| 关闭与返回 | 已替换 | AI 连接编辑器、学习提示、命令搜索、MCP 工具、任务编辑层、工作台返回 |
| 新增与保存 | 图标 + 文字 | AI 连接、知识编辑、知识模板、辅导计划、MCP Server |
| 测试与同步 | 图标 + 文字 | AI 模型发现、连接测试、粉笔错题同步 |
| 删除、撤销与确认 | 图标 + 文字 | 粉笔草稿、知识草稿、Vault 提案、AI 连接 |
| 仍保留文字 | 不图标化 | 页面页签、筛选器、状态标签、训练与业务语义动作 |

## 后续约束

- 新的纯图标按钮必须使用 `IconButton`，不得以 CSS 或字符伪造图标。
- 新增图标先登记到 `AppIconName`，保持 Lucide 线宽、尺寸和交互状态一致。
- 视觉回归继续抽查桌面与 390×844，重点检查图标与文字基线、按钮宽度和 Tooltip 碰撞。
