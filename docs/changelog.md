# Changelog

## 2026-06-23

- 修复自动化中心表单运行时崩溃：表单变更事件先提取 `value` / `checked` 到局部值，再进入 `setDraft` 或异步任务，避免 React 事件目标释放后读取 `null`。
- 统一自动化编辑器模板、周期选择和任务启用开关的事件处理风格；不改自动化仓储、调度、运行收件箱或数据结构。
- 新增 Playwright Chromium E2E 回归，并接入 GitHub Actions，覆盖自动化中心表单完整交互和运行时错误拦截。
- 扩展关键流程 E2E 护栏：覆盖 AI 连接保存与默认分配、Obsidian 桥接入口、知识资料导入、手动错题录入和个性化人设编辑。
- 新增移动 Chromium E2E 烟测，覆盖侧栏折叠展开、自动化表单、Obsidian 入口和 AI 连接表单在移动视口下可达且无页面级横向溢出。
- 修复知识资料确认入库后成功提示被数据刷新覆盖的问题，知识库保存、更新、删除和收藏等动作级反馈统一在刷新完成后发布。
- 拆出复盘工作台 shell 层和通知 hook，导航、页头、侧栏入口、同步提示从 `ReviewWorkspace` 中剥离，业务编排保持原行为。
- 新增总览页配置健康检查面板，只读聚合默认 AI 连接、Obsidian、自动化和学习数据闭环状态，并提供补齐入口。
- 新增配置健康契约测试和 E2E 导航回归，确保新库状态下可看到 AI 连接、Obsidian、自动化、导入和手动录入 CTA。
- 新增设置页本地诊断面板，汇总默认连接、Vault 权限、本地数据读取、自动化失败、浏览器能力和应用版本，并支持复制脱敏诊断报告。
- 修复本地新建知识资料首次同步到 Obsidian 时不会写入 Vault 的问题；未映射资料现在会生成托管 Markdown 并建立同步映射，错题仍通过待确认知识演进提案沉淀到 Vault。
- 优化首屏包体和大列表渲染：导入、自动化、设置、面试和辅导视图改为动态加载，AI 关联和 Obsidian 删除路径按需加载，错题库、知识资料和导入草稿改为渐进显示。
- 新增包体边界契约测试，防止 `ReviewWorkspace` 重新静态引入低频视图、导入 hook、AI/Obsidian 重型服务，并锁定 `pdfjs-dist` / `mammoth` 只在文件解析时动态加载。
- 自动化中心新增读取范围预览、试运行、运行详情和失败分类恢复入口；运行记录只持久化上下文摘要、字符数和恢复动作，不保存完整上下文或完整提示词。
- 自动化试运行允许用户显式调用默认文本连接，但不创建运行收件箱记录、不推进调度、不保存任务，也不落库知识演进提案。
- 新增自动化 AI 成功态 E2E：通过本地 mock Chat Completions provider 验证默认文本连接、试运行成功、立即运行成功、运行详情和授权上下文范围，不依赖真实 API Key 或外网。
- 继续瘦身 `ReviewWorkspace`：配置健康、诊断输入和恢复 CTA 导航抽到专用 hook，并新增静态契约防止跨模块胶水重新回到主工作台。
- 新增知识演进自动化成功态 E2E：使用本地 mock JSON provider 验证试运行不落库、立即运行生成待确认提案、收件箱详情和知识库提案展示。

- 知识演进确认闭环 v2 增加契约护栏：`merge` 提案只更新摘要、标签、AI 演进区、托管链接和来源引用，`link` 提案不修改正文，确认前复读 Vault 并拒绝过期 hash 覆盖。
- KnowledgeWorkspace 瘦身第一步：知识库列表渐进渲染、批量选择、批量删除和导出范围计算抽入 `useKnowledgeListController`；Obsidian repository 与知识演进 AI service 改为刷新或用户动作时动态加载，并用静态契约锁定边界。
- TutoringWorkspace 瘦身第一步：实时辅导的媒体源、关键帧采样、语音转写/朗读、本地草稿和当前轮次提交抽入 `useTutoringSessionController`，主工作台保留 tab、计划和关联视图接线。
- 新增 AI JSON 稳定性 helper，统一处理模型返回的 Markdown fence、对象/数组主体提取和稳定错误消息，并接入导入解析、粉笔解析、关联分析、知识内化、知识演进、面试和辅导 AI 服务。
- 数据层性能第二阶段保持无 schema 升级，新增静态契约防止缺少慢查询证据时创建 Dexie v14；新增 `docs/release-smoke.md` 作为真实浏览器与真实 Vault 发布验收清单。
## 2026-06-22

- 加固 File System Access 路径、权限恢复、失效句柄和托管目录缺失提示，并支持安全重新选择 Vault。
- 同步改为预检后统一提交，拒绝重复 `review-id`、并发同步和过期冲突覆盖。
- 演进提案支持失败后幂等重试，`link` 不再修改正文，未同步映射不得绕过冲突直接写入。
- 统一迁移早期 Vault 导入的完整时间戳为 `YYYY-MM-DD`，修复知识训练日期显示 `NaN/NaN`。
- 修复提案成功提示被刷新状态覆盖，并拒绝知识演进生成指向当前笔记自身的 Wikilink。
- 新增 GitHub Actions 质量门，统一检查 ESLint、契约测试、TypeScript 与生产构建。
- 修正 GitHub Actions 运行环境为 Node.js 22，匹配契约测试的 TypeScript 运行参数，避免 Node 20 阶段性失败。

## 2026-06-21

- 新增本地自动化中心，支持预设/自定义任务、固定周期、每日、每周、五段式 Cron、手动运行和未读收件箱。
- 自动化在应用打开时执行，关闭期间的漏跑合并一次；Web Locks、可续期 IndexedDB 租约和定义版本校验防止多标签重复请求。
- 自动化只读取明确授权的数据范围，知识演进来源与候选知识均受范围约束；结果或待确认提案不会自动改写知识库、训练记录或 Vault。
- 空白闪卡去除“添加角色图片”和“未命名角色”，只保留可访问的加号上传入口。
- 闪卡缩为桌面 7–8 列、移动三列；空卡改为浅色珠光纸面，金色镶边和底部蓝带裁到卡边。
- 知识库新增 Obsidian 托管目录双向桥接、Properties/Wikilink 解析、三方冲突和断开恢复。
- 错题、面试、辅导和知识资料可生成待确认的知识演进提案，确认后才写入 Obsidian AI 演进区块。
- 定制角色新增可持久化的闪卡/头像视图，卡片缩小并提高桌面与移动端排列密度。
- 角色卡和新上传图片统一改为 2:3，采用用户确认的金蓝透明边框，最高输出 2400×3600 WebP。
- 默认人设编辑器拆分固定头部与独立滚动正文，移除个性化页重复的语音连接卡片。
- 屏幕共享新增安全环境检查、轨道结束同步、来源状态和分类型错误提示，并明确只发送低频关键帧。
- AI 连接级客户端新增文本、多模态和语音能力校验，业务请求显式声明用途。
- 默认连接会自动清理不存在或能力不匹配的档案，默认文本连接更新同步兼容旧表。
- 设置页连接测试统一经过连接级客户端，移除旧 `/api/ai` 路由并明确缺失配置提示。
- 面试和辅导的配置按钮直达 AI 连接分区；辅导本地摘要降级会明确告知用户。
- 恢复工作台标题状态行，缺连接、保存结果和错误提示不再被共享标题组件吞掉。
- Noto Sans SC 改为仓库内 `next/font/local` 资产，离线和 CI 构建不再请求 Google Fonts。
