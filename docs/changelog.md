# Changelog

## 2026-08-09 · 0.4.x Data Reliability Phase 2

- Health issue 增加 repairability 分类和 Vault permission/mapping/hash 只读诊断；用户事实、凭据和 Vault 问题保持 manual-only。
- 增加唯一 targeted-safe repair：孤立对话运行步骤必须经过 preview、fresh V2 安全备份下载确认、精确事务删除与提交前完整性验证，不级联删除其他记录。
- 中断恢复结果区分 prepared discard 与 applying rollback；Bootstrap 成功后展示可见说明，失败保留 transfer job 并阻止业务启动，诊断页不再在加载时重复恢复。
- 新增 targeted repair 与 seeded applying startup Browser E2E；保持 Dexie v16、扩展库 v1、V2 格式、Vault 正文、Electron 权限和凭据边界不变。

## 2026-08-09 · 0.4.x Data Reliability Phase 1

- 建立完整数据资产、表级备份分类、版本化 localStorage 与 R0–R4 恢复等级矩阵；核心 36 表与分类策略不一致时 contract 失败，安全表继续显式排除。
- 保留 `LocalDataExportV2` 和早期 reader，新导出增加应用/schema、included/excluded 清单与逐表计数；恢复新增二次 preflight、敏感字段/记录预算校验和 apply 后验证。
- 跨 core/extension 恢复失败会验证旧快照回滚；回滚未完成时保留 transfer job。新增只读 Health Check，报告关键悬空、未完成事务与主密钥不可用而不泄漏凭据。
- 增加成功恢复与畸形包拒绝 Browser E2E；保持 `review_workspace` v16、`review_extensions` v1、Vault 正文、Electron 凭据和 Provider/MCP 边界不变。

## 2026-08-09 · 0.4 Application Layer Phase 1（Interview）

- 新增 `start-interview-session` 与 `submit-interview-turn` 两个轻量 Application Use Case，把 session/turn、AI 和 timer 的多步骤编排移出 React Hook；UI 状态、校验、刷新、通知、示例模式和评分触发保持在 Controller。
- 增加稳定失败阶段与部分结果，直接 Node 测试覆盖成功、AI/turn/session 写入失败、调用顺序、`shouldEvaluate` 两个分支及不隐式重试语义。
- 扩展架构守卫，禁止 Application 依赖 React、React DOM、Next UI、CSS、feature view、DOM 和 Electron preload global，并禁止 Platform 反向依赖 Application。
- 保持现有部分提交行为，不伪造 IndexedDB 与外部 AI 的事务，不升级 Dexie v16；Automation、Import 仍待迁移，Conversation 延后。

## 2026-08-09 · 0.3 Host Capability 与产品化准备

- 新增轻量 Host Capability Layer，统一暴露 Web / Electron 的 Vault 与原生窗口能力；业务 service 和 React hook 不再直接读取 Electron preload global。
- Electron adapter 仅包装既有 preload API，没有新增 IPC 权限、修改 sender 校验或改变 main/preload 安全边界；Web adapter 不模拟 Electron 能力。
- 增加 Host 架构契约，阻止 preload global 向业务代码回流，并禁止 platform 反向依赖 feature、service、database、server 或 React。
- README、0.3→1.0 Roadmap、Application Layer 迁移计划和数据可靠性边界与当前实现对齐。`review_workspace` 保持 v16，备份格式、凭据、Vault、Provider、MCP、Automation 和 UI 行为不变。
- 同 major 更新六个生产依赖修复安全公告，`npm run audit:prod` 归零；未使用强制审计修复，也未改变应用协议或数据结构。
